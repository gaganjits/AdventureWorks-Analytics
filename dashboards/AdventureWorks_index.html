Built With

The tech stack

Every chart, KPI, and interaction was built from raw CSV data — no BI tools, no drag-and-drop. Pure Python analytics + hand-coded dashboards.

🐍
Python / Pandas
Data loading, cleaning, merging 9 tables, computing KPIs, aggregations, and exporting analysis-ready JSON.
📊
Chart.js 4.4
All charts — line, bar, stacked, scatter/bubble, doughnut. Custom external tooltips, crosshair plugin, interaction modes.
🎨
HTML / CSS / JS
Zero frameworks. Custom dark theme, CSS animations, staggered reveals, hover strips, and drill-down interactions.
🗂️
AdventureWorks
Microsoft's sample dataset — 9 CSVs covering sales, products, customers, territories, and returns across 2015–2017.
⚡
Google Fonts
Outfit (display/headers) + Source Sans 3 (data/body). Chosen for warmth and readability across all screen sizes.
🔗
GitHub
Full source code, raw data, notebooks, and dashboard files available at github.com/gaganjits/AdventureWorks-Analytics.
